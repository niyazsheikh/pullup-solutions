# PullUp Website Structure

## Project Structure

```
weitbliqq/
├── index.html           # Landing page - Hero section only
├── about.html           # About page
├── services.html        # Services page
├── industries.html      # Industries page
├── process.html         # Process/Steps page
├── insights.html        # Insights/Projects page
├── contact.html         # Contact page with form
├── components/
│   └── navbar.html      # Navbar component (reference only)
└── assests/
    └── images/
        └── logo.png
```

## How to Use

1. **Open `index.html`** - This is your landing page with only the Hero section
2. **Click links in navbar** - Each navbar link navigates to a dedicated page
3. **All pages have the same navbar** - Consistent navigation across the site
4. **All pages have the same styling** - No visual changes, just organized content

## Page Contents

| Page | Content |
|------|---------|
| `index.html` | Hero section with call-to-action buttons |
| `about.html` | About company, mission, vision, values |
| `services.html` | All services offered (6 cards) |
| `industries.html` | Industry-specific services (8 cards) |
| `process.html` | 6-step consulting process |
| `insights.html` | Featured projects/portfolio |
| `contact.html` | Contact form with validation |
